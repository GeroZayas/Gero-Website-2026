putchar() and getchar() in C

putchar()

Writes one character to standard output (stdout).

int putchar(int c);

getchar()

Reads one character from standard input (stdin).

int getchar(void);

Canonical usage pattern

Character-by-character stream processing:

#include <stdio.h>  

int main() {  
    int c;  

    while ((c = getchar()) != EOF) {  
        putchar(c);  
    }  
}

This program copies stdin to stdout character by character (classic Unix filter behavior).
