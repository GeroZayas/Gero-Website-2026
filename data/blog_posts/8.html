TIl grep -v

grep -v means invert match.

It prints all lines that do NOT match the given pattern.

Syntax

grep -v "pattern" file

Example

grep -v "ERROR" app.log

→ shows every line except those containing ERROR.

Common uses

  • Remove comments:
grep -v '^#' config.conf
  • Remove blank lines:
grep -v '^$' file.txt
  • Chain filters (poor man’s data pipeline):
ps aux | grep -v root

Mental model

grep = keep matches grep -v = delete matches

That’s it. Simple, brutal, effective.
