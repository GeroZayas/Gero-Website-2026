FastAPI - Security - Bearer Tokens Explanation

Bearer Tokens - Simple Explanation

A Bearer token is a simple way to prove your identity when accessing a service or API. Think of it like a ticket or pass.

The Analogy

Imagine you go to a concert:

  1. You buy a ticket at the entrance
  2. You show the ticket to security
  3. Security sees your ticket and lets you in
  4. You can now access the concert

Bearer tokens work the same way:

  1. You log in with your username/password to get a token
  2. You include this token in your requests to an API
  3. The server checks the token to verify you are who you say you are
  4. If valid, the server lets your request through

How It Works

When you send a request to an API with a Bearer token, you include it in the header like this:

Authorization: Bearer YOUR_TOKEN_HERE

The word "Bearer" just means "the person/client carrying this token is allowed to access this resource."

Key Points

  • ✅ Simple: Just a string of characters you send along with your request
  • ✅ Stateless: The server doesn't need to remember anything about you (unlike sessions with cookies)
  • ✅ Secure: Often used with HTTPS to keep the token encrypted
  • ✅ Common: Used by most modern APIs and web services

Real-World Examples

  • GitHub API tokens
  • Google API keys
  • Twitter API tokens
  • Any "API key" you've ever used

That's it! Bearer tokens are just a straightforward way for services to verify "yes, this person is allowed to do this."

Example 1: Simple Bearer Token Authentication

from fastapi import FastAPI, Depends
from fastapi.security import HTTPBearer, HTTPAuthorizationCredentials

app = FastAPI()
security = HTTPBearer()

@app.get("/protected")
async def protected_route(credentials: HTTPAuthorizationCredentials = Depends(security)):
    token = credentials.credentials
    return {"message": "Access granted", "token": token}

How to use it:

  • Make a request with the header: Authorization: Bearer your_token_here
  • The endpoint will extract and return your token

Example 2: Complete OAuth2 with JWT (Login + Protected Routes)

from fastapi import FastAPI, Depends, HTTPException, status
from fastapi.security import OAuth2PasswordBearer, OAuth2PasswordRequestForm
from datetime import datetime, timedelta
from jose import JWTError, jwt
from pydantic import BaseModel

app = FastAPI()

# Configuration
SECRET_KEY = "your-secret-key-keep-it-safe"
ALGORITHM = "HS256"
ACCESS_TOKEN_EXPIRE_MINUTES = 30

oauth2_scheme = OAuth2PasswordBearer(tokenUrl="token")

class User(BaseModel):
    username: str

class Token(BaseModel):
    access_token: str
    token_type: str

# Simulate a user database
fake_users_db = {
    "johndoe": {"username": "johndoe", "password": "secret123"}
}

def verify_token(token: str = Depends(oauth2_scheme)):
    """Verify the bearer token"""
    try:
        payload = jwt.decode(token, SECRET_KEY, algorithms=[ALGORITHM])
        username = payload.get("sub")
        if username is None:
            raise HTTPException(status_code=401, detail="Invalid token")
        return username
    except JWTError:
        raise HTTPException(status_code=401, detail="Invalid token")

@app.post("/token", response_model=Token)
async def login(form_data: OAuth2PasswordRequestForm = Depends()):
    """Login endpoint - returns bearer token"""
    user = fake_users_db.get(form_data.username)

    if not user or user["password"] != form_data.password:
        raise HTTPException(status_code=401, detail="Incorrect username or password")

    # Create JWT token
    expires = datetime.utcnow() + timedelta(minutes=ACCESS_TOKEN_EXPIRE_MINUTES)
    token_data = {"sub": user["username"], "exp": expires}
    token = jwt.encode(token_data, SECRET_KEY, algorithm=ALGORITHM)

    return {"access_token": token, "token_type": "bearer"}

@app.get("/protected")
async def protected_route(username: str = Depends(verify_token)):
    """Protected route - requires valid bearer token"""
    return {"message": f"Hello {username}!"}

How to use it:

  1. Login to get a token:
curl -X POST "http://localhost:8000/token" \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "username=johndoe&password=secret123"

Response:

{
  "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "token_type": "bearer"
}
  1. Use the token to access protected routes:
curl -X GET "http://localhost:8000/protected" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."

Response:

{"message": "Hello johndoe!"}

Example 3: Custom Bearer Token Validation

from fastapi import FastAPI, Depends, HTTPException
from fastapi.security import HTTPBearer, HTTPAuthorizationCredentials

app = FastAPI()
security = HTTPBearer()

@app.get("/data")
async def get_data(credentials: HTTPAuthorizationCredentials = Depends(security)):
    token = credentials.credentials

    # Simple validation (in real world, verify JWT or database)
    if token != "valid-token-12345":
        raise HTTPException(status_code=403, detail="Invalid token")

    return {"data": "Secret information"}

Key Takeaway: Bearer tokens let you authenticate API requests by including a token in the Authorization header!

Where to Add Token Validation

You need to add validation logic. Here are the common approaches:

Option 1: Hardcoded Valid Token (Simplest)

from fastapi import FastAPI, Depends, HTTPException
from fastapi.security import HTTPBearer, HTTPAuthorizationCredentials

app = FastAPI()
security = HTTPBearer()

VALID_TOKEN = "my-secret-token-12345"

@app.get("/protected")
async def protected_route(credentials: HTTPAuthorizationCredentials = Depends(security)):
    token = credentials.credentials

    # Validate the token
    if token != VALID_TOKEN:
        raise HTTPException(status_code=403, detail="Invalid token")

    return {"message": "Access granted"}

Usage:

# ❌ Wrong token - gets rejected
curl -H "Authorization: Bearer wrong-token" http://localhost:8000/protected

# ✅ Correct token - gets accepted
curl -H "Authorization: Bearer my-secret-token-12345" http://localhost:8000/protected

Option 2: JWT Token (Better - What You Usually Do)

from fastapi import FastAPI, Depends, HTTPException
from fastapi.security import HTTPBearer, HTTPAuthorizationCredentials
from jose import jwt, JWTError

app = FastAPI()
security = HTTPBearer()

SECRET_KEY = "your-secret-key"
ALGORITHM = "HS256"

def verify_token(credentials: HTTPAuthorizationCredentials = Depends(security)):
    token = credentials.credentials

    try:
        # Decode and verify the JWT
        payload = jwt.decode(token, SECRET_KEY, algorithms=[ALGORITHM])
        username = payload.get("sub")

        if username is None:
            raise HTTPException(status_code=403, detail="Invalid token")

        return username
    except JWTError:
        raise HTTPException(status_code=403, detail="Invalid token")

@app.get("/protected")
async def protected_route(username: str = Depends(verify_token)):
    return {"message": f"Access granted to {username}"}

Option 3: Database Lookup (Most Realistic)

from fastapi import FastAPI, Depends, HTTPException
from fastapi.security import HTTPBearer, HTTPAuthorizationCredentials

app = FastAPI()
security = HTTPBearer()

# Simulate a database of valid tokens
valid_tokens_db = {
    "token-abc123": {"user": "john", "permissions": ["read"]},
    "token-xyz789": {"user": "jane", "permissions": ["read", "write"]}
}

def verify_token(credentials: HTTPAuthorizationCredentials = Depends(security)):
    token = credentials.credentials

    # Look up token in "database"
    if token not in valid_tokens_db:
        raise HTTPException(status_code=403, detail="Invalid token")

    return valid_tokens_db[token]

@app.get("/protected")
async def protected_route(token_data: dict = Depends(verify_token)):
    return {
        "message": f"Welcome {token_data['user']}!",
        "permissions": token_data["permissions"]
    }

Usage:

curl -H "Authorization: Bearer token-abc123" http://localhost:8000/protected
# Returns: {"message": "Welcome john!", "permissions": ["read"]}

Summary: Where Token Validation Happens

Where Example
Hardcoded in code Compare against a fixed string
JWT (decoded & verified) Decode the token and check signature + expiration
Database Look up token in a database/cache to see if it's valid
External service Call OAuth2 provider (Google, GitHub, etc.)

In real applications, you typically use JWT or database lookup — not the simple example I showed initially. The simple example was just to show how to extract the token, not how to validate it! ✅
