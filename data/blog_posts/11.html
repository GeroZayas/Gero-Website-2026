fgets() in C

Mental model

fgets() =
"Read a line, but never exceed the buffer limit."

fgets() reads a line of text from a stream (file or stdin) safely by limiting the number of characters read.

Example from File

#include <stdio.h>

int main() {
    FILE *file = fopen("data.txt", "r");
    char line[256];

    while (fgets(line, sizeof(line), file) != NULL) {
        printf("%s", line);
    }

    fclose(file);
    return 0;
}

Example from stdin

#include <stdio.h>

int main() {
    char buffer[100];

    printf("Enter text: ");
    fgets(buffer, sizeof(buffer), stdin);

    printf("You wrote: %s", buffer);
}
