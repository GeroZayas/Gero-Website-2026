Python Markdown: Rendering Markdown as HTML with Syntax Highlighting

1. The problem

Markdown (.md) is a plain-text format used for writing documentation, blog posts, articles, and technical content.

Browsers cannot render Markdown directly. They understand HTML.

If we want to build a blog, CMS, or documentation website using Python, we need to:

  1. Read a Markdown file.
  2. Convert Markdown into HTML.
  3. Support tables, code blocks, headings, lists, etc.
  4. Highlight programming-language syntax.
  5. Sanitize the resulting HTML to protect against XSS attacks.
  6. Display the resulting HTML in the browser.

We can accomplish this using three Python libraries:

Library Responsibility
markdown Convert Markdown into HTML
Pygments Syntax highlighting
nh3 HTML sanitization

2. Install the dependencies

pip install markdown pygments nh3

3. Convert Markdown into HTML

Python-Markdown is a mature Markdown parser.

Basic example:

import markdown

source = """
# My article

Hello **world**!

- Python
- JavaScript
- Odin
"""

html = markdown.markdown(source)

print(html)

Output:

<h1>My article</h1>
<p>Hello <strong>world</strong>!</p>
<ul>
<li>Python</li>
<li>JavaScript</li>
<li>Odin</li>
</ul>

Notice that Python-Markdown produces an HTML fragment, not a complete HTML document.

You can place this fragment inside a Jinja template.

4. Enable Markdown extensions

Markdown has additional features that can be enabled through extensions.

For example:

import markdown

md = markdown.Markdown(
    extensions=[
        "extra",
        "toc",
        "codehilite",
    ]
)

source = """
# Python example

## Tables

| Language | Type |
|---|---|
| Python | Dynamic |
| C | Static |

## Code

\```python
def hello():
    print("Hello world!")
\```

"""

html = md.convert(source)

What do these extensions do?

Extension Responsibility
extra Enables tables, footnotes, fenced code blocks, definition lists, and other features
toc Generates heading IDs and a table of contents
codehilite Integrates Pygments for syntax highlighting

Important: codehilite uses Pygments to generate syntax-highlighted HTML.

5. Understand syntax highlighting

A code block normally looks like this:

def hello():
    print("Hello")

Without syntax highlighting, the browser displays it as ordinary text.

Pygments analyzes the source code and identifies different tokens:

  • Keywords: def, return, if
  • Functions: print
  • Strings: "Hello"
  • Comments
  • Numbers
  • Operators

It generates HTML containing CSS classes.

Simplified example:

<div class="codehilite">
    <pre>
        <span class="k">def</span>
        <span class="nf">hello</span>():
            <span class="nb">print</span>("Hello")
    </pre>
</div>

The classes identify the different token types.

However, HTML classes alone do not provide colors.

We need CSS.

6. Generate the Pygments CSS stylesheet

Pygments includes predefined visual themes.

It provides a command-line utility called pygmentize.

Example:

pygmentize -S default -f html > pygments.css

Understanding the command:

Argument Meaning
pygmentize Pygments CLI utility
-S default Select the default theme
-f html Generate CSS for HTML output
> Redirect standard output into a file
pygments.css Destination stylesheet

You can choose other themes:

pygmentize -S monokai -f html > pygments.css

pygmentize -S dracula -f html > pygments.css

pygmentize -S nord -f html > pygments.css

To discover available themes:

pygmentize -L styles

Or programmatically:

from pygments.styles import get_all_styles

for style in get_all_styles():
    print(style)

You can also preview themes:

https://pygments.org/demo/

Include the stylesheet in your HTML

<link rel="stylesheet" href="/static/pygments.css">

Now the browser knows how to color the syntax-highlighted HTML.

The stylesheet is independent of your main CSS framework. It can coexist with Tailwind CSS.

7. Understand HTML sanitization and XSS

There is an important security consideration.

Python-Markdown allows raw HTML inside Markdown.

For example, someone could submit:

# Hello

<script>alert("XSS")</script>

If you render that Markdown and insert the resulting HTML into a browser, malicious scripts could execute.

This is called Cross-Site Scripting (XSS).

The solution is HTML sanitization.

We can use nh3:

import nh3

safe_html = nh3.clean(html)

nh3 removes or filters HTML elements and attributes that are not allowed by its sanitization policy.

Important: sanitization should happen after Markdown rendering, not before.

Also, sanitization is not a replacement for proper application security. Configure allowed tags and attributes according to your needs.

8. Complete example

This combines everything:

from pathlib import Path

import markdown
import nh3


def render_markdown(source: str) -> str:
    md = markdown.Markdown(
        extensions=[
            "extra",
            "toc",
            "codehilite",
        ],
        extension_configs={
            "codehilite": {
                "guess_lang": False,
                "use_pygments": True,
            }
        },
    )

    html = md.convert(source)

    return nh3.clean(html)


source = Path("article.md").read_text(encoding="utf-8")

html = render_markdown(source)

Path("output.html").write_text(html, encoding="utf-8")

This example:

  1. Reads a Markdown file.
  2. Converts Markdown to HTML.
  3. Supports tables and fenced code blocks.
  4. Generates syntax-highlighted code using Pygments.
  5. Sanitizes the generated HTML.
  6. Saves the resulting HTML fragment.

The Pygments CSS must also be included in the HTML page displaying the fragment.

9. Important architectural distinction

Markdown is plain text.

You do not need a Markdown library to read or write .md files.

Python's standard library is sufficient:

from pathlib import Path

# Read Markdown
source = Path("article.md").read_text(encoding="utf-8")

# Write Markdown
Path("article.md").write_text(
    "# My article\n\nHello world!",
    encoding="utf-8",
)

The Markdown library is needed when you want to parse Markdown and transform it into another representation, such as HTML.

Python-Markdown is not a full Markdown editor or a guaranteed lossless Markdown round-trip serializer.
