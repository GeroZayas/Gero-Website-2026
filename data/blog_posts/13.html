Working with files fopen() fclose() and more

In C (ANSI C / C99), file I/O is performed through the stdio library, which uses an abstraction called a stream represented by the FILE type. The central function is fopen(), which opens a file and returns a pointer to a FILE object used by other functions.

All these functions operate on a FILE * handle.

#include <stdio.h>

1. fopen() — Opening a File

Prototype

FILE *fopen(const char *filename, const char *mode);

Parameters

  • filename → path to the file
  • mode → how the file will be accessed

Return value

  • Returns a FILE * pointer if successful
  • Returns NULL if the file cannot be opened

File Modes

Mode Meaning
"r" Read only
"w" Write only (creates or truncates file)
"a" Append
"r+" Read and write
"w+" Read/write (overwrite file)
"a+" Read/append

Binary modes (important on Windows):

"rb"
"wb"
"ab"

Example

#include <stdio.h>

int main(void)
{
    FILE *file = fopen("data.txt", "r");

    if(file == NULL)
    {
        printf("Failed to open file\n");
        return 1;
    }

    printf("File opened successfully\n");

    fclose(file);
    return 0;
}

2. fclose() — Closing a File

Prototype

int fclose(FILE *stream);

Purpose

Closes a file and flushes buffered data to disk.

Return

  • 0 → success
  • EOF → error

Example

FILE *f = fopen("test.txt", "w");

fprintf(f, "hello\n");

fclose(f);

3. Writing to Files

fprintf()

Formatted output to a file.

int fprintf(FILE *stream, const char *format, ...);

Example:

FILE *f = fopen("numbers.txt", "w");

fprintf(f, "Value = %d\n", 10);

fclose(f);

This works the same way as printf() but writes to a file instead of stdout.

fputc()

Write one character

int fputc(int c, FILE *stream);

Example:

fputc('A', file);

fputs()

Write a string

int fputs(const char *str, FILE *stream);

Example

fputs("hello world\n", file);

4. Reading from Files

fscanf()

Formatted input from a file.

int fscanf(FILE *stream, const char *format, ...);

Example

int x;

FILE *f = fopen("numbers.txt", "r");

fscanf(f, "%d", &x);

fclose(f);

fgetc()

Read one character.

int fgetc(FILE *stream);

Example

int c;

while((c = fgetc(file)) != EOF)
{
    putchar(c);
}

fgets()

Read a string (safe line reading).

char *fgets(char *str, int n, FILE *stream);

Example

char buffer[128];

fgets(buffer, sizeof(buffer), file);

5. Binary I/O (Block I/O)

For performance and raw data.

fread()

size_t fread(void *ptr, size_t size, size_t count, FILE *stream);

Example

int buffer[100];

fread(buffer, sizeof(int), 100, file);

fwrite()

size_t fwrite(const void *ptr, size_t size, size_t count, FILE *stream);

Example

int data[100];

fwrite(data, sizeof(int), 100, file);

These operate on blocks of memory, which is far more cache-friendly and faster than character I/O for large data.

6. File Position Functions

fseek()

Move file cursor.

int fseek(FILE *stream, long offset, int origin);

Origin options:

SEEK_SET
SEEK_CUR
SEEK_END

Example

fseek(file, 0, SEEK_END);

ftell()

Get current position.

long ftell(FILE *stream);

rewind()

Reset to beginning.

rewind(file);

7. Example: Full File Read

#include <stdio.h>

int main(void)
{
    FILE *f = fopen("test.txt", "r");

    if(!f) return 1;

    char buffer[256];

    while(fgets(buffer, sizeof(buffer), f))
    {
        printf("%s", buffer);
    }

    fclose(f);

    return 0;
}

8. How It Works Internally (Performance View)

FILE streams are buffered.

Meaning:

Disk  ->  stdio buffer  ->  your program

Advantages:

  • Fewer system calls
  • Higher throughput
  • Sequential access is very fast

But it also means:

  • data may stay in memory until fflush() or fclose().

9. Important Errors to Handle

Always check:

FILE *f = fopen("file.txt", "r");

if(!f)
{
    perror("fopen");
    return 1;
}

Ignoring this is one of the most common C bugs.

10. Typical File I/O Workflow

fopen()
   ↓
read/write (fgetc, fscanf, fread, fprintf...)
   ↓
fclose()
