SQLite Python - safe ways to pass variables (Security)

For SQLite in Python, you have two main ways to pass variables safely. Both methods prevent SQL injection by treating your data as "values" rather than executable code.

1. The Positional Way (?)

This is the most common method. You use a question mark as a placeholder and pass a tuple of values as the second argument.

import sqlite3

db = sqlite3.connect(":memory:") # Using an in-memory DB for this example
user_id = 101

# Note: The second argument MUST be a tuple. 
# (user_id,) with a comma is how Python defines a single-item tuple.
db.execute("SELECT * FROM users WHERE id = ?", (user_id,))

2. The Named Way (:name)

As you mentioned, this uses a dictionary. It is much cleaner for queries with multiple variables.

import sqlite3

db = sqlite3.connect(":memory:")
params = {"id": 101, "status": "active"}

# The keys in the dict must match the names after the colons
query = "SELECT * FROM users WHERE id = :id AND status = :status"
db.execute(query, params)

Comparison Summary

Feature Positional (?) Named (:label)
Data Container Tuple (val1, val2) Dictionary {"key": val}
Best For Simple queries with 1-2 variables Complex queries or many variables
Ordering Must match the order in the SQL Order doesn't matter
Readability Low (lots of ?) High (descriptive names)

⚠️ Common Mistake to Avoid

Never use Python's f-strings or % operator inside the string:

# ❌ DANGEROUS - Vulnerable to SQL Injection
db.execute(f"SELECT * FROM users WHERE name = '{user_name}'") 

# ✅ SAFE - The database driver handles the data
db.execute("SELECT * FROM users WHERE name = ?", (user_name,))
