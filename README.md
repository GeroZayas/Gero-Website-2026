# Gero Zayas' Website

[gerozayas.com](https://gerozayas.com)

## Notes on this exercise

> - 100% Handmade with FastAPI and Datastar
> - All components are Jinja2 and hand-made custom HTML Components.
> - The main idea of this exercise is not to add dependencies isanmuch as possible nor frameworks (React, Vue, Angular, etc.).
